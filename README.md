## Simulation-Engine
My very much so WIP program for me to run simulations with configurable rules and flexible object management.

## Features
    * Can store, modify, and execute predefined code for objects over time.
    * Can take metric units as inputs for a timestep without erroring

## Technologies
    * Python for portability
    * DearPyGUI for graphics

## Usage
It doesn't do much beyond open a window, calculate frametimes, and convert some randomized test vectors into time steps.
If you want to use it yourself, most of the work is on you to make it work for your set of objects. The API hasn't even been started yet.
